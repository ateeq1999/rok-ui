# Getting help

- **How do I ...?** Start with the [README](README.md), the guides in [docs/guide](docs/guide)
  and the API docs on [docs.rs](https://docs.rs/rok-ui). `cargo run --example gallery` shows
  every component.
- **Questions and ideas:** open a
  [GitHub issue](https://github.com/ateeq1999/rok-ui/issues/new/choose) with the feature
  request template. For a new component, link its page on ui.shadcn.com.
- **Bugs:** use the bug report template. Include your OS, the rok-ui and gpui versions and a
  minimal snippet.
- **Database (`db` feature) problems:** if the problem is in a rok-db query rather than in
  rok-ui's glue, report it to [rok-db](https://github.com/ateeq1999/rok-db/issues).
- **Security problems:** report them privately, as described in [SECURITY.md](SECURITY.md).

rok-ui is maintained by volunteers. Issues are triaged as time allows; a minimal reproduction
gets the fastest answer.
