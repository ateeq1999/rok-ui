# Migrating to 0.7

0.7 adds forms, stores, router v2, file-based routes, devtools and the `cargo rok-ui` CLI. No
rok-ui API is removed. One dependency change can affect apps that use the `db` feature.

## The `db` feature uses rok-db 0.3

`rok_ui::db::rok_db` is now rok-db 0.3 (was 0.1). Two rok-db changes can break code that uses
rok-db models directly:

- `Column` predicates need the model to implement `Model`. Columns built by `#[derive(Model)]`
  already do; hand-written columns need `M: Model`.
- `find` takes `impl IntoKey` instead of the key type. Plain keys still work
  (`User::find(&db, 42)`); a composite key is a tuple (`Membership::find(&db, (team, user))`).

If your app depends on rok-db directly as well, update it to `0.3` so both use the same
version.

## Nothing else to change

- `db::use_query` is still deprecated (see [0.6](0.6.md)) and will be removed in 0.8.
- New features are opt-in: `form` is in `full`; `router`, `devtools` and `persist` are
  enabled by name.
